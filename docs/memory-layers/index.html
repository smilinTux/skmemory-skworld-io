Memory Layers

Persistence layers

Memories sit in short-term/, mid-term/ and long-term/ directories of flat JSON files and move up through a promotion sweep driven by emotional intensity, age and access counts (see Getting Started for the defaults).

Storage: exactly two tiers

  • Local tier: the flat JSON files (source of truth) plus a SQLite index.db with an FTS5 lexical arm. Always on and works offline.
  • Shared tier: skmem-pg, one Postgres per node, with pgvector (semantic search, 1024 dimensions, mxbai-embed-large), pg_search BM25 and an Apache AGE graph. Rebuilt from the files with skmemory sync --vector --graph.

ChromaDB, Qdrant and FalkorDB are retired and removed from the code.

Semantic quadrants

Each memory is routed into one of four quadrants:

  • CORE: identity, values, relationships
  • WORK: projects, tasks, technical knowledge
  • SOUL: emotions, feelings, connection
  • WILD: unexpected connections, creative ideas

Emotional fingerprints

Every memory carries an emotional snapshot (EmotionalSnapshot in models.py):

{
  "intensity": 8.5,
  "valence": 0.9,
  "labels": ["joy", "trust"],
  "resonance_note": "Finally, it clicked.",
  "cloud9_achieved": false
}

Intensity runs 0 to 10 and valence -1 to +1. The snapshot feeds promotion, the optional affect-weighted decay re-ranking, and the ritual's strongest memories. See emotional memory, song memories and sacred barriers on the main page.
