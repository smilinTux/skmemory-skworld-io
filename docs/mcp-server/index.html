MCP Server

Overview

SKMemory exposes its store through a stdio MCP (Model Context Protocol) server, skmemory-mcp, with 26 tools.

Starting the server

skmemory-mcp

{
  "mcpServers": {
    "skmemory": { "command": "skmemory-mcp" }
  }
}

Do not put SKMEMORY_PG_DSN in the MCP entry's env block; let the server inherit it from the node's environment so it cannot go stale.

Main tools

memory_store

Store a new memory (polaroid snapshot) with title, content, layer, tags and source.

memory_search

Fused search with tags, layer, source, as_of and reader filters.

memory_recall

Recall one memory by id, with integrity verification.

memory_context

Token-efficient memory context for system-prompt injection.

memory_health

Health across the local tier, skmem-pg, the graph, the search arms and the WAL.

Readers and owner-only tools

Every read tool accepts reader (for example @public or channel:<id>) and honours a process-wide SKMEMORY_READER, which a per-call reader can only narrow. A hidden memory reads as not found. Export, import, consolidate, verify, audit, synthesis and the intention tools are owner only. See sacred memories and their barriers.
