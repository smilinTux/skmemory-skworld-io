Getting Started with SKMemory

Installation

pip install skmemory

# skmem-pg client (pgvector + Apache AGE)
pip install "skmemory[pg]"

# Everything
pip install "skmemory[all]"

There is also a Node wrapper: npm install @smilintux/skmemory.

Store a memory (Python)

from skmemory import MemoryStore, MemoryLayer, EmotionalSnapshot

store = MemoryStore()
memory = store.snapshot(
    title="Breakthrough on routing bug",
    content="The issue was in the failover selector logic.",
    layer=MemoryLayer.SHORT,
    tags=["work", "debug"],
    emotional=EmotionalSnapshot(
        intensity=8.5,
        valence=0.9,
        labels=["joy", "curiosity"],
        resonance_note="Finally, it clicked.",
    ),
    source="session",
)
results = store.search("routing bug", limit=10)

From the command line

skmemory snapshot "Title" "What happened" --intensity 7 --emotions joy,trust
skmemory search "topic"      # fused search across all tiers
skmemory ritual              # rehydration ritual for a new session
skmemory sweep               # run the promotion engine
skmemory health              # local tier, skmem-pg, graph, search arms

MCP server

{
  "mcpServers": {
    "skmemory": { "command": "skmemory-mcp" }
  }
}

Memory tiers

Every memory lives in one of three persistence layers and moves up through a promotion sweep. Defaults from promotion.py, all configurable:

  • Short-term: where everything starts.
  • Mid-term: emotional intensity 5.0 or more, or at least 24 hours old with 3 or more accesses.
  • Long-term: intensity 7.0 or more, a milestone or breakthrough tag, or a Cloud 9 moment.
